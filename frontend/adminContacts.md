# Admin Contacts (Read-only)

**Endpoints**:
- `GET /admin/contacts?is_read=false` → unread first
- `PUT /admin/contacts/:id/read` → mark read
- `DELETE /admin/contacts/:id` → delete

**Frontend**: Table name/email/subject/date/status badge (new/leído), Eye (mark read), Trash.

**No create (from contact form public).**

Production ready.
